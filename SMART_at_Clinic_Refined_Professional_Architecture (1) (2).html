This map illustrates the backend logic behind SMART@Clinic, not a physician-facing interface. It defines how each physician’s specialty and clinical focus determine the default visualizations, key metrics, and analyses automatically presented in their personalized dashboard.

How the hierarchy works

Each physician’s SMART@Clinic profile determines the default view. The dashboard then applies saved preferences and patient-specific adjustments.
